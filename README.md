# Notes REST API (Node.js + Express + MongoDB)

RESTful API для управления заметками с подключением к облачной базе данных MongoDB Atlas через ODM Mongoose. Реализованы полные CRUD-операции, модульная архитектура приложения, логирование HTTP-запросов и централизованная обработка ошибок.

**Live Demo (Render):** [https://onrender.com](https://nodejs-hw-ozrn.onrender.com)

---

## 🛠 Технологический стек

- **Node.js & Express** — серверная платформа и маршрутизация
- **MongoDB & Mongoose** — облачная NoSQL база данных и моделирование схем
- **http-errors** — генерация стандартизированных HTTP-ошибок
- **pino-http & pino-pretty** — структурированное логирование входящих запросов
- **dotenv** — управление переменными окружения
- **cors** — настройка политики кросс-доменных запросов

## ⚙️ Установка и локальный запуск

1. **Клонируйте репозиторий и перейдите в нужную ветку:**

   ```bash
   git clone https://github.com
   cd nodejs-hw
   git checkout 02-mongodb
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта и добавьте следующие параметры:

   ```env
   PORT=3000
   MONGO_URL=ваша_строка_подключения_к_mongodb
   ```

4. **Запустите сервер:**
   - В режиме разработки (с автоматическим перезапуском):
     ```bash
     npm run dev
     ```
   - В продакшен-режиме:
     ```bash
     npm start
     ```

## 🚀 Доступные эндпоинты API

| Метод    | Маршрут          | Описание                            | Статус успеха |
| :------- | :--------------- | :---------------------------------- | :------------ |
| `GET`    | `/notes`         | Получить список всех заметок        | `200 OK`      |
| `GET`    | `/notes/:noteId` | Получить одну заметку по её ID      | `200 OK`      |
| `POST`   | `/notes`         | Создать новую заметку               | `201 Created` |
| `PATCH`  | `/notes/:noteId` | Обновить существующую заметку по ID | `200 OK`      |
| `DELETE` | `/notes/:noteId` | Удалить заметку по ID               | `200 OK`      |

### Структура объекта заметки (`Note`)

- `title` _(String, обязательное)_ — заголовок заметки.
- `content` _(String, необязательное)_ — текст заметки (по умолчанию `""`).
- `tag` _(String, необязательное)_ — категория из списка: `Work`, `Personal`, `Meeting`, `Shopping`, `Ideas`, `Travel`, `Finance`, `Health`, `Important`, `Todo` (по умолчанию `"Todo"`).
- `createdAt` / `updatedAt` _(Date)_ — автоматические временные метки создания и обновления.
