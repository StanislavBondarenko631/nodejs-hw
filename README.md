# Notes REST API (Node.js + Express + MongoDB)

RESTful API для управления заметками с подключением к облачной базе данных MongoDB Atlas через ODM Mongoose. Реализованы полные CRUD-операции, фильтрация по тегам и тексту, пагинация, строгая валидация входящих данных через `celebrate` (`Joi`), модульная архитектура приложения, логирование HTTP-запросов и централизованная обработка ошибок.

**Live Demo (Render):** https://onrender.com

---

## 🛠️ Технологический стек

- **Node.js & Express** — серверная платформа и маршрутизация
- **MongoDB & Mongoose** — облачная NoSQL база данных, индексация и моделирование схем
- **celebrate & Joi** — декларативная валидация параметров маршрута, query-параметров и тела запроса
- **http-errors** — генерация стандартизированных HTTP-ошибок
- **pino-http & pino-pretty** — структурированное логирование входящих запросов
- **dotenv** — управление переменными окружения
- **cors** — настройка политики кросс-доменных запросов

## ⚙️ Установка и локальный запуск

1. **Клонируйте репозиторий и перейдите в нужную ветку:**

```bash
git clone https://github.com
cd nodejs-hw
git checkout 03-validation
```

2. **Установите зависимости:**

```bash
npm install
```

3. **Настройте переменные окружения:** Создайте файл `.env` в корне проекта и добавьте следующие параметры:

```env
PORT=3000
MONGO_URL=ваша_строка_подключения_к_mongodb
```

4. **Запустите сервер:**

- В режиме разработки (с автоматическим перезапуском):

```bash
npm run dev
```

- В продакшен-режиме:

```bash
npm start
```

## 🚀 Доступные эндпоинты API

| Метод    | Маршрут          | Описание                                                    | Статус успеха |
| :------- | :--------------- | :---------------------------------------------------------- | :------------ |
| `GET`    | `/notes`         | Получить список заметок с поддержкой пагинации и фильтрации | `200 OK`      |
| `GET`    | `/notes/:noteId` | Получить одну заметку по её `ObjectId`                      | `200 OK`      |
| `POST`   | `/notes`         | Создать новую заметку                                       | `201 Created` |
| `PATCH`  | `/notes/:noteId` | Обновить существующую заметку по `ObjectId`                 | `200 OK`      |
| `DELETE` | `/notes/:noteId` | Удалить заметку по `ObjectId`                               | `200 OK`      |

> При передаче некорректных параметров запроса, невалидного `noteId` или неверного тела запроса сервер возвращает статус `400 Bad Request` с детальным описанием ошибки валидации.

### Параметры запроса для `GET /notes`

- `page` _(необязательный)_ — номер страницы (целое число ≥ 1, по умолчанию `1`).
- `perPage` _(необязательный)_ — количество заметок на странице (целое число от `5` до `20`, по умолчанию `10`).
- `tag` _(необязательный)_ — фильтрация по точному совпадению тега из списка `TAGS`.
- `search` _(необязательный)_ — регистронезависимый текстовый поиск по полям `title` и `content`.

**Пример ответа `GET /notes?page=1&perPage=10&tag=Todo`:**

```json
{
  "page": 1,
  "perPage": 10,
  "totalNotes": 2,
  "totalPages": 1,
  "notes": [
    {
      "_id": "6af2dd022bd0d3a77de76b16",
      "title": "Buy groceries",
      "content": "Milk, bread, eggs",
      "tag": "Todo",
      "createdAt": "2026-11-19T10:00:00.000Z",
      "updatedAt": "2026-11-19T10:00:00.000Z"
    }
  ]
}
```

### Структура объекта заметки (`Note`)

- `title` _(String, обязательное)_ — заголовок заметки (минимум 1 символ).
- `content` _(String, необязательное)_ — текст заметки (по умолчанию `""`).
- `tag` _(String, необязательное)_ — категория из списка: `Work`, `Personal`, `Meeting`, `Shopping`, `Ideas`, `Travel`, `Finance`, `Health`, `Important`, `Todo` (по умолчанию `"Todo"`).
- `createdAt` / `updatedAt` _(Date)_ — автоматические временные метки создания и обновления.
